# Apple Inc. Financial Statement Analysis
This project covers a 3-year analysis of Apple Inc. (2023–2025), including:
- Horizontal & Vertical Analysis
- Ratio Analysis (Margins, ROA, ROE)
- Financial Dashboard
- Analyst Insights

## Tools Used
- Excel (financial modeling, dashboards)
- Data visualization

Built as part of my Investment Banking Portfolio to demonstrate applied financial analysis skills.
